# Πρόβλεψη τιμών ηλεκτρικής ενέργειας στην ελληνική αγορά επόμενης ημέρας: ARIMAX και Random Forest

## Περιγραφή έργου
Το έργο προσπαθεί να προβλέψει τη μέση ημερήσια τιμή της αγοράς επόμενης ημέρας στην Ελλάδα και συγκρίνει τα μοντέλα ARIMAX και Random Forest, σε δύο περιόδους: την ενεργειακή κρίση (έλεγχος: 2022) και την πρόσφατη περίοδο (έλεγχος: 01/04/2026–28/09/2026).

## Περιγραφή των αρχείων κώδικα

- **`entsoe_download.py`**: Αναλαμβάνει τη λήψη δεδομένων από το API της πλατφόρμας διαφάνειας ENTSO-E. Τα δεδομένα περιλαμβάνουν τις τιμές ηλεκτρικής ενέργειας, το φορτίο, τις προβλέψεις παραγωγής από ανανεώσιμες πηγές ενέργειας (ΑΠΕ) και τις ανταλλαγές ηλεκτρικής ενέργειας με γειτονικές χώρες.
- **`entsoe_gr_pipeline_v2.py`**: Αναλαμβάνει τη λήψη μετεωρολογικών δεδομένων από το Open-Meteo και την ενοποίησή τους με τα υπόλοιπα δεδομένα σε ωριαία βάση. Το παραγόμενο σύνολο δεδομένων αποθηκεύεται σε αρχείο της μορφής `dataset_hourly_<περίοδος>.parquet`.
- **`entsoe_gr_models_v4.py`**: Πραγματοποιεί τη δημιουργία του ημερήσιου συνόλου δεδομένων, τον υπολογισμό των μεταβλητών εισόδου, την εφαρμογή των μοντέλων ARIMAX, Random Forest, ARX και naive, καθώς και την αξιολόγηση των προβλέψεων με τη μέθοδο walk-forward. Επιπλέον, υπολογίζει τις μετρικές αξιολόγησης και εκτελεί τους προβλεπόμενους ελέγχους, συμπεριλαμβανομένης της διερεύνησης ακραίων τιμών (spikes).

## Περιβάλλον ανάπτυξης και εκτέλεσης

Ο κώδικας αναπτύχθηκε και εκτελέστηκε σε περιβάλλον Windows 11, με χρήση της Python 3.13 και του Visual Studio.

## Πηγές δεδομένων και απαιτήσεις πρόσβασης

**ENTSO-E Transparency Platform:** Για τη λήψη δεδομένων μέσω του API απαιτείται προσωπικό κλειδί πρόσβασης (API token), το οποίο αποκτάται μέσω προσωπικού λογαριασμού στην πλατφόρμα, σύμφωνα με τις οδηγίες της ENTSO-E.

**Open-Meteo:** Για τη λήψη ιστορικών μετεωρολογικών δεδομένων χρησιμοποιείται το Historical Weather API ([https://open-meteo.com/](https://open-meteo.com/)), χωρίς να απαιτείται κλειδί API.

## Διαδικασία εκτέλεσης

Για κάθε εξεταζόμενη περίοδο (την περίοδο της ενεργειακής κρίσης και την πρόσφατη περίοδο) τα επιμέρους στάδια εκτελούνται από τον φάκελο που περιέχει τα αρχεία κώδικα.

Για την περίοδο της ενεργειακής κρίσης εκτελούνται διαδοχικά οι ακόλουθες εντολές:

```bash
python entsoe_download.py crisis
python entsoe_gr_pipeline_v2.py weather crisis
python entsoe_gr_pipeline_v2.py build crisis
python entsoe_gr_models_v4.py crisis
```

Οι εντολές εκτελούν, αντίστοιχα, τη λήψη των δεδομένων ENTSO-E, τη λήψη των μετεωρολογικών δεδομένων, την ενοποίηση των δεδομένων και, τέλος, την εφαρμογή των μοντέλων και την αξιολόγηση των προβλέψεων.

Το ενοποιημένο ωριαίο σύνολο δεδομένων αποθηκεύεται στο αρχείο `dataset_hourly_crisis.parquet`, ενώ τα αποτελέσματα της μοντελοποίησης αποθηκεύονται στον φάκελο `results_crisis/`.

Για την πρόσφατη περίοδο ακολουθείται η ίδια διαδικασία, με χρήση της αντίστοιχης παραμέτρου περιόδου στις εντολές εκτέλεσης.

## Αρχεία αποτελεσμάτων και εναλλακτικές εκδοχές

Τα αποτελέσματα αποθηκεύονται στον φάκελο `results_<περίοδος>/`. Ανάλογα με την εξεταζόμενη εκδοχή, δημιουργούνται αντίστοιχοι υποφάκελοι, όπως `τελική`, `με_καιρό`, `χωρίς_net_import` και `net_import_ίδιας_ημέρας`.

Οι επιμέρους εκδοχές επιτρέπουν τη σύγκριση των αποτελεσμάτων υπό διαφορετικές προδιαγραφές εισόδου, σύμφωνα με τις αντίστοιχες ρυθμίσεις του κώδικα.

## Μεθοδολογία μοντελοποίησης
Στο έργο εξετάζονται οι ακόλουθες προσεγγίσεις πρόβλεψης.
- **ARIMAX**: Το ARIMAX είναι μοντέλο αυτοπαλίνδρομης ολοκληρωμένης κινητής μέσης τιμής με εξωγενείς μεταβλητές.
- **Random Forest**: Το Random Forest είναι μέθοδος μηχανικής μάθησης που βασίζεται στον συνδυασμό πολλών δέντρων απόφασης. Στη ΔΕ χρησιμοποιείται για εργασίες παλινδρόμησης και ταξινόμησης, με σταθερό τυχαίο σπόρο 42.
- **ARX**: Το ARX είναι αυτοπαλινδρομικό μοντέλο με εξωγενείς επεξηγηματικές μεταβλητές.
- **Naive**: Χρησιμοποιούνται ως σημεία αναφοράς για τη σύγκριση της απόδοσης των πιο σύνθετων στατιστικών και υπολογιστικών μοντέλων.

## Αναπαραγωγιμότητα και διαδικασία αξιολόγησης

Για το μοντέλο Random Forest χρησιμοποιείται σταθερός τυχαίος σπόρος (`random_state=42`), τόσο στην παλινδρόμηση όσο και στην ταξινόμηση. Τα naive μοντέλα και το μοντέλο ARX, το οποίο εκτιμάται με τη μέθοδο των ελαχίστων τετραγώνων, δεν περιλαμβάνουν τυχαίο στοιχείο στη διαδικασία εκτίμησης. Το μοντέλο ARIMAX εκτιμάται με τη μέθοδο της μέγιστης πιθανοφάνειας, μέσω αριθμητικής βελτιστοποίησης, χωρίς τη χρήση τυχαίου σπόρου.

Η αξιολόγηση πραγματοποιείται με τη μέθοδο walk-forward, με επανεκτίμηση των μοντέλων ανά 30 ημέρες και χρήση διευρυνόμενου συνόλου εκπαίδευσης (expanding training window). Με τον τρόπο αυτό, το σύνολο εκπαίδευσης διευρύνεται διαδοχικά καθώς ενσωματώνονται νέες παρατηρήσεις, σύμφωνα με τη διαδικασία αξιολόγησης που έχει υλοποιηθεί.
